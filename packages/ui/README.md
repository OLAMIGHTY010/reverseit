# @smartreversal/ui

Shared design tokens, financial status badges, and accessible UI components for the SMARTREVERSAL operations console.

## Contents
- **Theme Tokens**: Standard colors, high-contrast dark themes, alert badges.
- **Financial Statuses**: Strongly-typed statuses matching ledger, switch, and reconciliation lifecycle states (`SUCCESS`, `PENDING_MAKER`, `PENDING_CHECKER`, `REVERSED`, `UNCERTAIN`, `FAILED`).
